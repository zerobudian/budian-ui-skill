# 国际化架构(zh-CN / en)

> 默认能力:除非用户明确关闭,页面支持中英双语、自动检测浏览器语言、手动切换并持久化。架构综合 GFW X(自动检测 + data-i18n)、budianai(设置内切换 + html lang 同步)、vellunote(22 语言 data-t)三处 Observed 实现。

## 文案组织(禁止散落硬编码)

```js
const messages = {
  "zh-CN": {
    "nav.product": "产品",
    "hero.kicker": "边缘消息队列 · 2026",
    "hero.title": "让消息，抵达每一个边缘。",
    "hero.lede": "Aurora Relay 是面向边缘计算的低延迟消息基础设施。",
    "cta.start": "开始使用",
    "stat.latency": "端到端延迟",
    "table.empty": "暂无数据"
  },
  "en": {
    "nav.product": "Product",
    "hero.kicker": "EDGE MESSAGING · 2026",
    "hero.title": "Messages that reach every edge.",
    "hero.lede": "Aurora Relay is low-latency messaging infrastructure for edge computing.",
    "cta.start": "Get started",
    "stat.latency": "End-to-end latency",
    "table.empty": "No data yet"

```

- 键名按 `区域.元素` 命名;新增键必须同时落两语言,缺键在控制台告警(开发期)。
- 文案集中在字典,DOM 与业务 JS 中不得出现裸双语文案。

## 检测与持久化

```js
const LOCALE_KEY = "budian-locale";

function detectLocale() {
  let saved = null;
  try { saved = localStorage.getItem(LOCALE_KEY); } catch (e) {}
  if (saved === "zh-CN" || saved === "en") return saved;      // 手动 > 浏览器
  const langs = navigator.languages || [navigator.language || "en"];
  return langs.some(l => /^zh/i.test(l)) ? "zh-CN" : "en";    // zh* → zh-CN,其余 → en
}
```

## 应用机制(data-i18n)

```html
<button data-i18n="cta.start">开始使用</button>
<input data-i18n-attr="placeholder:search.placeholder,aria-label:search.label">
<title data-i18n="page.title"></title>  <!-- 或 JS 直接设 document.title -->
```

```js
function applyLocale(locale) {
  const dict = messages[locale];
  document.documentElement.lang = locale;
  document.title = dict["page.title"];
  document.querySelectorAll("[data-i18n]").forEach(el => {
    const key = el.dataset.i18n;
    if (dict[key] != null) el.textContent = dict[key];
  });
  document.querySelectorAll("[data-i18n-attr]").forEach(el => {
    el.dataset.i18nAttr.split(",").forEach(pair => {
      const [attr, key] = pair.split(":").map(s => s.trim());
      if (dict[key] != null) el.setAttribute(attr, dict[key]);
    });
  });
}
```

- HTML 中的默认文案使用主语言(zh-CN),保证无 JS 时也可读(渐进增强)。
- 切换语言后同步:`<html lang>`、`document.title`、meta description、全部 aria-label/placeholder、动态生成的 toast/错误信息。

## 日期 / 数字 / 货币

```js
new Intl.DateTimeFormat(locale, { dateStyle: "medium", timeStyle: "short" })
  .format(new Date());
new Intl.NumberFormat(locale === "zh-CN" ? "zh-CN" : "en-US")
  .format(1289400);                        // 1,289,400 / 1.289.400 风格按 locale
new Intl.NumberFormat("zh-CN", { style: "percent", maximumFractionDigits: 1 }).format(.996);
```

禁止手写 `toFixed` + 千分位拼接;相对时间用 `Intl.RelativeTimeFormat`。

## 布局容忍(英文约长 30%)

- 禁止 `width: NNNpx` 绑定中文文案长度;按钮、导航、标签全部自适应内容。
- 导航条在 en + 768px 下不得换行/溢出——必要时收纳进"更多"菜单。
- 卡片标题不设固定高,允许两行。
- 表单 label 在 en 下加长时换行而非截断。
- 测试矩阵:两个 locale × 375/768/1440 全过。

## 语言切换 UI

- 顶栏紧凑按钮(`中 / EN` 或图标 + `aria-label`)或设置面板内的分段选择(budianai Observed)。
- 切换即时生效(无刷新),写入 localStorage。
- `dir` 本系统仅支持 LTR(zh-CN/en);若扩展 RTL 语言,需补 `dir="rtl"` 镜像规则(vellunote 有 RTL 先例)。
