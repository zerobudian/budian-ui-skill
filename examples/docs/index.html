GETTING STARTED

快速开始

五分钟内把一个 Markdown 文件夹变成一个可部署的文档站。不需要 Node,不需要配置文件,不需要数据库。

安装

Glasshouse 是单个静态二进制。从发布页下载对应平台的版本,放进 PATH,即可使用。

SHELL 
curl -fsSL https://glasshouse.example/install.sh | sh
glasshouse --version

目录结构

Glasshouse 约定优于配置。把 Markdown 放进 docs/,标题取自第一个 H1,目录自动生成。

TEXT 
my-project/
├── docs/
│   ├── index.md        # 首页
│   ├── guide.md        # 指南
│   └── reference/      # 自动成为二级目录
│       └── cli.md
└── glasshouse.toml     # 可选

配置

所有配置都有合理的默认值。下面是最小配置示例:

TOML 
title = "我的项目文档"
lang  = "zh-CN"

[theme]
light = true
dark  = true

提示深色模式默认跟随系统,无需额外配置。如需强制单主题,把 dark 设为 false。

静态托管

构建产物是纯静态文件,任何静态托管服务都可以直接部署:

SHELL 
glasshouse build          # 输出到 _site/
npx wrangler pages deploy _site

自定义主题

主题就是一个 CSS 变量文件。覆盖标记(token)即可改变外观,不必触碰模板:

CSS 
:root {
  --gh-accent: #237cff;   /* 强调色 */
  --gh-radius: 16px;      /* 卡片圆角 */
}

注意不要在模板里内联硬编码颜色。所有外观值都应通过 token 提供,否则深色模式会失效。
